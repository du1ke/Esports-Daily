# 完美电竞选手自动评分-增加主队等级

## 下载与安装

1. 前往 [Releases](https://github.com/du1ke/-/releases)，下载最新版的 `Windows-x64-Release.zip` 附件。
2. 解压整个压缩包，双击 `Esports-Daily.exe`。
3. 点击「扫码登录」，用自己的完美电竞账号扫码。

## 开始评分

1. 登录后，程序会尝试读取并选中你的主队。也可以点击「直接读取主队」重试。
2. 在「评分战队」下拉框里选中战队，选择会自动保存。列表里没有的战队，可以粘贴官网战队主页链接并按回车添加。
3. 点击「开始评分」。程序会在该战队已结束的比赛里寻找可评分的选手或教练，确认 10 分后发送战队评论，例如 `lets go TYLOO!!!`。
4. 在「运行动态」和「评分与评论记录」里查看结果。

主队评分和评论每天完成一次。手动给其他战队评分不占用主队当天的次数。可在「偏好设置」里管理开机启动和每天零点执行。

## 退出登录

点击「退出登录」会清除程序在本机保存的登录状态。关闭窗口只会最小化。要完全退出，请在 Windows 系统托盘里选择「退出程序」。
